# MindVault

**Fully offline personal knowledge base + AI chat**

Upload your PDFs, notes, and documents. Chat with them privately using a local LLM.  
No data leaves your machine.

Built by [Mohammad Mojiz Abbas](https://github.com/mojizatoffice-sys)  
3rd Year B.Tech CSD | Ghaziabad, India

---

## Why MindVault?

Most AI tools send your private documents to the cloud.  
MindVault keeps everything local using Ollama + vector search so you can safely chat with your study material, research papers, or personal notes.

## Current Features (v0.1)

- [ ] Upload PDF / TXT / Markdown
- [ ] Automatic chunking + embedding
- [ ] Local vector store (Chroma)
- [ ] Chat interface with source citations
- [ ] Streaming responses
- [ ] Fully offline (Ollama)

## Planned

- Multiple document collections
- Better citation UI

## Tech Stack

- **Backend**: FastAPI + Python
- **LLM & Embeddings**: Ollama (local)
- **Vector Database**: ChromaDB
- **Frontend**: Next.js + TypeScript + Tailwind (coming)
- **Document parsing**: pypdf + unstructured
